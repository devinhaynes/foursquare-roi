# Foursquare ROI

A Next.js application for calculating and analyzing return on investment for properties.

## Features

- Property management and tracking
- ROI calculations and analytics
- User authentication and protected routes
- Customizable settings and preferences
- Responsive design with modern UI components

## Getting Started

First, install dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
